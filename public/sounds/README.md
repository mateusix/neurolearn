# Efeitos de resposta

Origem: Kenney — Interface Sounds (1.0), https://kenney.nl/assets/interface-sounds

Licença: CC0; texto original em KENNEY-LICENSE.txt.

- correct.wav: confirmation_001.ogg, duração 0,29 s.
- retry.wav: error_004.ogg, duração 0,103 s.

Conversão para PCM WAV mono 16 bits/44,1 kHz, pico limitado a 0,55 e entrada/saída suavizadas. Os arquivos são locais; reprodução com ganho baixo e somente com Efeitos sonoros ligados. Se o arquivo falhar, o aplicativo usa seus tons locais como alternativa. Sem API ou biblioteca adicional no aplicativo.
